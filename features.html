Ro-Link features

The tools behind live game management.

Ro-Link connects Discord staff workflows to Roblox operations. This page explains what each part does and where it fits into day-to-day community management.

On this page

Live servers Moderation Player identity Staff access Reports Setup tools
01

Live server visibility

Give staff a shared view of active Roblox servers without asking players for server details or switching between separate admin tools.

  • View active server sessions
  • Check player presence and counts
  • Review live server information from the dashboard
02

Discord moderation controls

Keep supported game-management actions close to the conversation where staff receive reports and coordinate responses.

  • Run supported moderation actions from Discord
  • Use slash commands with clear staff permissions
  • Act without sharing Roblox owner credentials
03

Linked player identity

Connect Discord members with their Roblox accounts so staff know which player they are helping, reviewing, or moderating.

  • Link Discord and Roblox accounts
  • Verify a member before protected submissions
  • Use linked identity during staff review
04

Role-based staff access

Assign access according to staff responsibilities instead of giving every moderator the same level of control.

  • Map dashboard roles to Discord staff
  • Control access to logs and staff notes
  • Restrict management tools to trusted roles
05

Reports and staff context

Keep community reports, linked player details, and internal staff context together so reviews are easier to follow.

  • Accept reports through the public report flow
  • Review submissions with linked account context
  • Keep staff-only notes behind permissions
06

Guided Roblox setup

Connect the Discord bot, web dashboard, and Roblox experience through a guided setup rather than wiring each part together manually.

  • Connect through the Roblox Studio plugin
  • Register the experience with Ro-Link
  • Use the documentation for setup and troubleshooting
